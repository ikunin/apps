プライバシーポリシー

最終更新：2026年9月9日。iOS版MorseHeroアプリと本サイトに適用されます。

MorseHeroは何も収集しません。解析SDKも、クラッシュレポーターも、広告も、追跡も、アカウントもありません。アプリ自身がネットワークに接続することはなく、唯一やりとりする相手はAppleのApp Storeだけ、それも購入や復元のときだけです。マイクはトーンの有無を測るだけで破棄されます。音声が録音されることも、ディスクに書き込まれることも、端末の外に出ることもありません。

端末に残るもの

すべてです。具体的には：

  • 練習の記録 — どの文字に出会ったか、それぞれ何回正解したか、各セッションでどれだけの速さで受信できていたか
  • どの文字とどの文字を取り違えやすいか（ドリルがそこへ戻ってこられるように）
  • 設定 — 速度、間隔、側音の高さ、カードを消すかどうか、毎日のリマインダーを使うかどうか
  • 練習用に貼り付けたテキスト

いずれもどこにもアップロードされません。アプリ自身のコンテナの中にあり、アプリを削除すればすべて消えます。毎日のリマインダーは、有効にした場合、端末が予定するローカル通知です。サーバーは関与せず、何も送信されません。

購入について

MorseHero Proは1回限りの買い切りで、決済はすべてAppleが扱います。お支払い情報、Apple アカウント、お名前を当方が見ることはありません。アプリはAppleに何を購入済みかを尋ね、その答えを端末に保存します。だからオフラインでも購入したものが使えます。

MorseHero Proはファミリー共有に対応していません。購入したApple アカウントで、そのアカウントにサインインしているすべての端末で有効になります。購入の復元では、そのアカウントが所有しているかをAppleに尋ねるだけで、ほかには何も分かりません。

お子さまについて

本アプリのレーティングは4+で、年齢を問わず個人情報を一切収集しません。チャット、共有されるコンテンツ、ソーシャル機能、ウェブブラウザ、広告のいずれもありません。練習用に貼り付けたテキストはその端末に留まります。

理由の記載が必要な API

Appleは、特定のAPIとその使用理由の申告をアプリに求めています。MorseHeroは3つ申告しています。UserDefaults（理由CA92.1、ご自身の端末上のご自身の設定のため）、システム起動時刻（35F9.1、電鍵の計測に壁時計ではなく単調増加する時計を使うため）、ファイルのタイムスタンプ（C617.1、アプリ自身が自分のコンテナ内に書いた練習記録のため）。この申告はPrivacyInfo.xcprivacyとしてアプリに同梱され、収集データの一覧は空です。

本ウェブサイトについて

本ページは GitHub Pages が配信する静的ファイルです。Cookie を設定せず、スクリプトを埋め込まず、フォントや画像を外部から読み込まず、解析も行いません。GitHub はサービス運営の一環としてサーバーへのリクエストを記録する場合があります。GitHub のプライバシーに関する声明 をご覧ください。

変更について

本ポリシーが変更される場合は、冒頭の日付も変わります。プライバシーを後退させる変更は新しいバージョンのアプリとともに行われ、そのバージョンのリリースノートに記載されます。
