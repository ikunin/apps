プライバシーポリシー

最終更新：2026年8月3日。アプリ Harbor Rush と本サイトに適用されます。

広告なし、アプリをまたぐ追跡なし、アカウントなし。 広告 SDK も広告 ID もなく、登録するものもありません。したがって App Tracking Transparency の確認も表示されません——追跡する対象がないからです。ゲームが送信するものは以下のとおりで、いずれも匿名です。

端末に残るもの

プレイの記録はお客様のものです。具体的には：

  • どの港をクリアしたか、ベストタイム、スコア
  • 解放済みの地域と、購入の端末内の記録
  • 設定——音、触覚フィードバック、色覚配慮の記号、通知

どれも当方にアップロードされません。アプリを削除すればすべて消えます。購入は「購入を復元」で戻ります——その記録を持っているのは Apple であり、当方ではありません。

購入について

地域の解放と World Pass は買い切りで、処理はすべて Apple が行います。お支払い情報も、Apple アカウントも、お名前も、こちらからは一切見えません。アプリは「何を所有しているか」を Apple に尋ね、その答えを端末に保存します。購入したものがオフラインでも使えるようにするためです。

購入はファミリー共有に対応しています。ご家族が購入を共有すると、Apple はアプリに「あなたに権利がある」とだけ伝えます。その人が誰かは伝えません。

匿名の利用カウンター

本ゲームは、匿名化された利用シグナル——ラウンドが始まった、港をクリアした——を TelemetryDeck（プライバシー重視の解析サービス）へ送信することがあります。氏名、メールアドレス、広告 ID、端末 ID は一切含まれず、アプリやウェブサイトをまたいでお客様を追跡する目的には使われません。Apple のプライバシー表示ではこれを製品とのやり取り／お客様と紐付けられない／トラッキングには使用しないとして記載しています。お客様を識別するものは送られないため、遊び方からお客様にたどり着くことはできません。

対戦

対戦の招待は短いコードです——港の番号とタイムだけ。氏名も識別子も端末情報も含まれず、メッセージ、メール、チャットアプリなど、お客様が選んだ手段で送られます。当方のサーバーは経由しません。そもそも当方はサーバーを持っていません。

Game Center

ランキングと実績は任意で、Apple のものです。ご利用の場合、Game Center の識別情報とスコアは Apple のプライバシーポリシー に基づき Apple が扱います。Game Center を切っても、ゲームの中身はまったく同じです。

お子さまについて

本ゲームのレーティングは 9+ です。頻度の低い、穏やかなアニメ表現——船どうしがぶつかり、一部の港には海賊と沿岸砲が登場します。年齢を問わず、誰からも個人情報を収集しません。チャットも、ユーザー投稿も、ソーシャル機能も、ウェブブラウザーも、広告もありません。

理由の記載が必要な API

Apple は、特定の API とその使用理由の申告を求めています。Harbor Rush が申告しているのは一つ、UserDefaults（理由 CA92.1）——ご自身の設定をご自身の端末に保存するためです。この申告は PrivacyInfo.xcprivacy としてアプリに同梱されています。

本ウェブサイトについて

本ページは GitHub Pages が配信する静的ファイルです。Cookie を設定せず、スクリプトを埋め込まず、フォントや画像を外部から読み込まず、解析も行いません。GitHub はサービス運営の一環としてサーバーへのリクエストを記録する場合があります。GitHub のプライバシーに関する声明 をご覧ください。

変更について

本ポリシーが変更される場合は、冒頭の日付も変わります。プライバシーを後退させる変更は新しいバージョンのアプリとともに行われ、そのバージョンのリリースノートに記載されます。
