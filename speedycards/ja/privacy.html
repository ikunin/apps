プライバシーポリシー

最終更新：2026年8月3日。iOS アプリ SpeedyCards と本サイトに適用されます。

SpeedyCards は何も収集しません。 解析 SDK も、クラッシュレポートも、広告も、トラッキングも、アカウントもありません。アプリが自ら通信することはなく、唯一やり取りする相手は Apple の App Store で、購入または復元のときだけです。

端末に残るもの

すべてです。具体的には：

  • ベストタイム、連続記録、XP、テーブルランク
  • 獲得または購入したテーブルと、購入の端末内の記録
  • 設定——音、触覚フィードバック、通知、どのテーブルで遊んでいるか
  • ご自身で保存したバックアップ。置いた場所に書き出される普通の zip ファイルです

どれも当方にアップロードされません。連続記録と XP は<strong>お客様ご自身の iCloud キー・バリュー・ストレージ</strong>にも保存され、Apple アカウントのもとで端末間を同期します——当方が読むことはできません。アプリを削除すると端末内の記録は消えます。購入は「購入を復元」で戻ります。その記録を持っているのは Apple です。

購入について

曲パック、取りこみ、クリップアート、SpeedyCards Pro はいずれも買い切りで、処理はすべて Apple が行います。お支払い情報も、Apple アカウントも、お名前も、こちらからは一切見えません。アプリは「何を所有しているか」を Apple に尋ね、その答えを端末に保存します。購入したものがオフラインでも使えるようにするためです。

購入はファミリー共有に対応しています。ご家族が購入を共有すると、Apple はアプリに「あなたに権利がある」とだけ伝えます。その人が誰かは伝えません。

お子さまについて

本アプリは子ども向けに作られており、レーティングは 4+ です。年齢を問わず、誰からも個人情報を収集しません。チャットも、共有されるユーザー投稿も、ソーシャル機能も、ウェブブラウザーも、広告もありません。お子さまが絵文字から作ったクリップアートは、その端末に留まります。

理由の記載が必要な API

Apple は、特定の API とその使用理由の申告を求めています。SpeedyCards が申告しているのはただ一つ、UserDefaults（理由 CA92.1）——ご自身の設定をご自身の端末に保存するためです。この申告は PrivacyInfo.xcprivacy としてアプリに同梱されており、収集データの一覧は空です。

本ウェブサイトについて

本ページは GitHub Pages が配信する静的ファイルです。Cookie を設定せず、スクリプトを埋め込まず、フォントや画像を外部から読み込まず、解析も行いません。GitHub はサービス運営の一環としてサーバーへのリクエストを記録する場合があります。GitHub のプライバシーに関する声明 をご覧ください。

変更について

本ポリシーが変更される場合は、冒頭の日付も変わります。プライバシーを後退させる変更は新しいバージョンのアプリとともに行われ、そのバージョンのリリースノートに記載されます。
