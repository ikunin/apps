JustTalk
홈 지원 개인정보 이용약관 AI Impressum 다른 앱

개인정보 처리방침

최종 업데이트: 2026년 9월 27일. macOS용, iPhone 및 iPad용(키보드 포함), Windows용 JustTalk 앱과 이 웹사이트에 적용됩니다.

JustTalk에는 분석 기능도, 크래시 리포터도, 추적 기능도, 저희 쪽 계정도 없습니다. 앱이 스스로 어딘가에 접속하는 일은 없습니다. 다만 평소 사용 시 직접 선택하고 키를 보유한 클라우드 음성 인식 및 다듬기 서비스로 음성을 전송하므로, 여기서 중요한 대부분은 이 방침이 아니라 그 제공업체의 방침입니다. 온디바이스 옵션은 어디로도 아무것도 전송하지 않지만, 이는 기본값이 아니라 예외적인 선택지입니다.

첫 번째 부분은 모든 버전에 적용됩니다. Mac, iPhone 및 iPad, Windows 버전은 몇 가지 점에서 다르며, 각각 별도의 부분에서 설명합니다.

  • 모든 버전 — 무엇을 보관하고, 무엇을 누구에게 보내는지
  • Mac — 키체인, App Store 구매, macOS 권한, 앱 맥락 정보
  • iPhone 및 iPad — 키보드와 전체 접근, 키체인, App Store 구매
  • Windows — 자격 증명 관리자, 라이선스 요청, Windows 권한, 앱 맥락 정보
  • 이 웹사이트

모든 버전

기기에 남는 것

클라우드 백엔드를 선택하지 않는 한 전부입니다. 다음은 로컬에 저장되며 JustTalk가 업로드하는 일은 없습니다:

  • 모드, 사용자 사전, 작업
  • 사용 통계 — 받아쓴 단어 수, 절약한 시간, 예상 지출액
  • 녹음된 오디오. 받아쓰는 동안만 메모리에 보관되며 디스크에는 기록되지 않습니다
  • 설정한 서비스의 API 키. 각 플랫폼에서 어디에 보관되는지는 아래 해당 부분에 나와 있습니다
  • 온디바이스 받아쓰기를 사용하는 경우 내려받은 음성 모델

JustTalk에는 서버가 없으므로, 서버에서 지울 사용자의 데이터도 없습니다. 기기에 있는 데이터를 지우는 방법은 각 플랫폼 부분에 나와 있습니다.

클라우드 백엔드를 선택하면

JustTalk는 오디오 또는 그 받아쓰기 결과를 사용자가 설정한 제공업체 — Google, OpenAI, Groq, Mistral, Anthropic, 또는 직접 입력한 서버 주소 — 로 전송할 수 있습니다. 그 데이터는 이 방침이 아니라 해당 업체의 개인정보 처리방침에 따라 다뤄지며, JustTalk는 그들이 무엇을 보관하는지 알 수 없습니다. 녹음을 시작하기 전에 어떤 제공업체가 활성화되어 있는지 앱에 표시되며, 온디바이스 받아쓰기로 전환하면 무엇도 기기 밖으로 나가지 않습니다.

개인정보 보호 모드

모든 버전에 있는 스위치 하나로 받아쓰기를 온전히 기기 안에서만 처리합니다. 음성은 기기에서 인식되고, 다듬기는 기기의 언어 모델로만 이뤄지며(모델이 없으면 건너뜁니다), Mac과 Windows에서는 입력 중인 앱에 대한 정보도 읽지 않습니다. 끄면 설정해 두었던 그대로 돌아갑니다.

JustTalk가 AI를 어떻게 사용하는지, AI가 생성한 것을 어떻게 표시하는지, EU AI 법이 사용자에게 무엇을 요구하는지는 AI 관련 고지에서 확인하세요.

어린이

JustTalk는 어린이용 앱이 아니라 성인을 위한 생산성 도구입니다. 나이와 상관없이 누구의 개인정보도 수집하지 않습니다.

Mac

키가 보관되는 곳

API 키는 macOS 키체인에 저장됩니다. 앱의 Application Support 폴더를 삭제하면 JustTalk가 보관하는 나머지 모든 데이터가 삭제됩니다.

말과 함께 전송되는 것

다듬기 모델을 사용할 때 JustTalk는 결과가 상황에 맞도록 — 메일 앱에서의 답장, 채팅에서의 메시지처럼 — 받아쓰는 앱의 이름만 모델에 알려 줍니다. 개인정보 보호 모드를 켜면 앱 이름조차 읽히거나 전송되지 않습니다.

구매

Mac용 JustTalk Pro는 전적으로 Apple이 처리하는 1회성 구매입니다. App Store는 구매 자격이 있는지만 앱에 알려줄 뿐, 이름이나 이메일, 결제 정보를 앱이 보는 일은 없습니다. 이 구매는 가족 공유를 지원합니다. 가족 그룹의 구성원이 공유해 주면 Apple은 자격이 있다는 사실만 앱에 알려줄 뿐, 그 사람에 대한 다른 어떤 정보도 알려주지 않습니다.

권한

JustTalk는 마이크를 사용하며, 회의를 녹음할 때는 시스템 오디오도 사용합니다. 둘 다 macOS가 먼저 권한을 요청합니다. 결과를 앞에 있는 앱에 붙여넣으려면 손쉬운 사용 권한이 필요합니다. 연락처, 위치, 사진, 건강 데이터는 전혀 읽지 않습니다.

iPhone 및 iPad

키보드

JustTalk 키보드는 전체 접근 허용을 요청합니다. 키보드가 네트워크에 접속하거나 자체 앱과 무언가를 공유하기 전에 iOS가 요구하는 권한입니다. 그 권한으로 하는 일은 정확히 다음과 같습니다.

  • 입력란에 이미 있는 내용은 읽지 않습니다. 글자를 입력하고, 자신이 입력한 내용만 기억합니다. 되돌리기와 작업이 그 문장만을 대상으로 삼기 위한 것입니다.
  • 입력한 내용을 기록하지 않습니다. 누른 키는 입력 중인 앱으로만 들어가며 다른 어디로도 가지 않습니다.
  • 키보드가 스스로 어딘가로 보내는 일은 없습니다. iOS는 키보드가 마이크를 열도록 허용하지 않으므로 녹음은 JustTalk 앱이 하며, 설정한 서비스와 통신하는 것도 키보드가 아니라 앱입니다.
  • 세션이 실행되는 동안 JustTalk 앱이 마이크를 잡고 있고 iOS는 그 시간 내내 주황색 표시를 켜 둡니다. 정직한 표시입니다. 세션을 멈출 때까지 마이크는 실제로 사용 가능한 상태입니다.
  • 받아쓰기는 기본적으로 기기에서 전사되며 아무것도 전송하지 않습니다. 음성에서 제공자를 고를 때 비로소 오디오가 어딘가로 전송됩니다.
  • 키보드는 어떤 앱에 입력하고 있는지 알 수 없으므로, 말과 함께 앱 이름이 전송되는 일은 없습니다.

기록 없음

JustTalk는 받아쓴 내용을 기록하지 않습니다. 업데이트하면 이전 버전이 남긴 기록은 삭제됩니다.

키가 보관되는 곳

API 키는 iOS 키체인에 저장됩니다. 앱을 삭제하면 JustTalk가 보관하는 모든 데이터가 삭제됩니다.

구매

iPhone 및 iPad용 JustTalk Pro는 Mac용과는 별개인 1회성 구매이며 전적으로 Apple이 처리합니다. App Store는 구매 자격이 있는지만 앱에 알려줄 뿐, 이름이나 이메일, 결제 정보를 앱이 보는 일은 없습니다. 가족 공유를 지원하며, 가족 구성원이 공유해 주더라도 그 사람에 대해 앱에 알려지는 것은 없습니다.

권한

앱은 마이크와 음성 인식 권한을 요청합니다. 온디바이스 받아쓰기를 사용하면 음성 인식은 기기 안에서만 이뤄집니다. 연락처, 위치, 사진, 건강 데이터는 전혀 읽지 않습니다.

Windows

Windows 버전은 Apple 제품이 아니며 App Store에서 판매되지 않으므로, 위의 Apple 관련 부분은 어느 것도 적용되지 않습니다.

키가 보관되는 곳

API 키는 Windows 자격 증명 관리자에 저장됩니다. 앱을 제거하면 JustTalk가 보관하는 나머지 모든 데이터가 삭제되지만, 키는 자격 증명 관리자에서 직접 제거할 때까지 그곳에 남습니다.

말과 함께 전송되는 것

다듬기 모델을 사용할 때 JustTalk는 결과가 상황에 맞도록 — 메일 앱에서의 답장, 채팅에서의 메시지처럼 — 받아쓰는 앱의 이름만 모델에 알려 줍니다. 개인정보 보호 모드를 켜면 앱 이름조차 읽히거나 전송되지 않습니다.

라이선스

Windows 라이선스는 아직 판매하지 않습니다. 라이선스를 요청할 때 이메일로 보내 주시는 요청에는 직접 입력한 이름과 이메일 주소, 그리고 키가 해당 PC에서 작동하도록 하기 위한 PC 하드웨어 식별자의 단방향 해시가 담깁니다. 이 정보는 키를 발급하고 재발급하는 데에만 사용하며 다른 용도로는 쓰지 않습니다.

권한

JustTalk는 마이크를 사용하며, 회의를 녹음할 때는 시스템 오디오도 사용합니다. 사용 가능 여부는 개인 정보 및 보안 아래의 마이크 설정이 결정합니다. 연락처, 위치, 사진, 건강 데이터는 전혀 읽지 않습니다.
