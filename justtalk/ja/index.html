どのアプリにも音声入力

JustTalk は iPhone と iPad のキーボードです。どのアプリでも — メッセージ、メール、WhatsApp、メモ、AI チャット — マイクをタップして話せば、カーソルの位置に文字が現れます。すでに整った状態で：「えーと」はなく、句読点が付き、言い直しも反映されています。

話せば、書ける

  • マイクは文字キーの上に。入力の途中でも、キーボードを切り替えずに音声入力できます。
  • 話すそばから言葉が表示され、間を置くたびに、その文が整形されて入力されます。
  • 言い直しが優先。「火曜日 — いや、木曜日」は「木曜日」と入力されます。
  • どこからでも開始：アクションボタン、コントロールセンター、背面タップで、アプリを開かずにセッションを始められます。
  • 何も失われません：接続が切れても iPhone 自身の音声認識が引き継ぎ、前回の音声入力は 10 分間、ワンタップでもう一度入力できます。

フル機能のキーボードとしても

  • 文字キーの上に単語の候補、そして入力する前に次の単語を。
  • 入力を自動修正は、手を止めたときにタイプミスと句読点を直します — 言い回しは変えません。
  • 名前を一度直せば、JustTalk が覚えておくか尋ねるので、次からは正しく綴られます。
  • 絵文字、カーソルキー、取り消しとやり直し、ライトとダークの両方で。

Mac と Windows では：ホットキーひとつ

ホットキーを押したまま話して、離すだけ。整形されたテキストが、いま手前にあるアプリに貼り付けられます — 書いているメール、文書、ターミナル、チャット。小さなカプセルが聞き取り中であることを示すだけで、ほかに邪魔するものはありません。モード、フレーズ、アクションは電話と同じ。フレーズとアクションのパレットはキーひとつで開きます。

モード：同じ言葉を、行き先に合わせて

タップひとつで、音声入力の書き方が変わる

モードは整形のための指示です。キーボードかメニューでひとつ選べば、すべての音声入力がそのスタイルで仕上がります：

  • 一般 — あなたの言葉を整えるだけ。何も足さず、言い換えません。
  • フォーマル — 改まった丁寧な文に。大家さん、銀行、役所への手紙に。
  • メール — メールの本文を、あなた自身の口調で。
  • SNS — フィード向けの投稿を、絵文字とハッシュタグ付きで。
  • AIプロンプト — ChatGPT、Claude、Gemini 向けの明確なプロンプト：まず依頼内容、次に背景と条件。
  • 翻訳 — ある言語で話し、別の言語で入力。

自分のモードを書くことも、ひと言の説明から AI に指示を書かせることもできます。このモードをテストは、あなたの各言語で 6 つのサンプル音声入力を実行し、うまくいかなかった点をわかりやすい言葉で示します。Mac と Windows では、アプリに合わせて適切なモードに切り替わります — Mail や Outlook ではメール、ChatGPT では AIプロンプト。iPhone ではショートカットのオートメーションが同じことをします。

ある言語で話し、別の言語で入力

音声入力しながら翻訳

  • 翻訳と入力する言語を選びます。あなたの言語のどれで話しても、テキストは翻訳され、ほかの音声入力と同じように整えられて届きます。
  • 名前、数字、住所は話したとおりに残り、口調もあなたのまま — 短いメッセージは短いメッセージのままです。
  • キーボードには入力先の言語が表示され、入力後にはどの言語から翻訳したかが表示されます。
  • Mac、Windows、iPhone、iPad のどれでも同じように。

フレーズ：何度も書くことを

タップひとつ、ショートカットひとつ、またはひと言で

  • 住所、口座情報、定型の返信、署名：一度保存すれば、キーボードやパレットからタップひとつで挿入できます。
  • テキストショートカット：住所に「adr」というショートカットを付ければ、入力してスペースを押すだけで住所が入ります。入力中には JustTalk がフレーズを提案します。
  • 話して挿入：音声入力の中で話したひと言が、そのフレーズになります。
  • グループはタブに分かれ、ピン留めしたフレーズが先頭、次によく使うもの。最初はスターターセットから。

アクション：選択したテキストを書き直す

自分の指示を、どんなテキストにも

  • テキストを選択して — 何も選ばなければフィールド全体 — アクションをタップ：短く、やわらかく、箇条書きに、文法を直す、英語に。
  • アクションは自分の言葉で書くことも、説明して AI に指示を書かせることもできます。
  • 結果はその場でテキストを置き換え、取り消しを一度押せば元に戻ります。
  • iPhone と iPad ではキーボードから、Mac と Windows ではパレットから。

JustTalk Notes：会議、ボイスノート、タスク

自分で書かなくていい議事録

  • 会議：Mac と Windows では通話の両側を、iPhone と iPad ではその場の会議を。話すそばから文字起こしされ、そのあとに議事録：要約、決定事項、タスク。
  • ボイスノート：思いついたことを話せば、選んだ形式で書き起こされます。
  • すべての会議のタスクをひとつのリストに — 誰が、何を、いつまでに — そして同じ顔ぶれでまた会うときには、前回から残っているものも。
  • フォルダに質問：答えには元になったノートが示され、どの項目も、それが話された瞬間へリンクしています。
  • フォルダ、タグ、検索、PDF・Word・Markdown への書き出し。Apple デバイスでは、オンにすれば iCloud で同期されます。

あなたの言葉は、あなたのもの

入力したことも話したことも、私たちに送られることは決してありません。

iPhoneとiPadでは、キーボードがフルアクセスを求めます。フルアクセスがあると、JustTalkキーボードはJustTalkアプリが聞き取った内容を受け取り、あなたが選んだサービスに接続できます。フルアクセスがないと、キーボードは文字を入力することしかできません。

  • 私たちには一切送られません。サーバーなし、分析なし、アカウントなし。
  • 音声入力は選んだサービスにだけ送られるか、デバイスに留まります。
  • パスワード欄では常に Apple のキーボードが使われます。
  • 音声入力した内容は保存されません。

ご自身で確かめられます：iPhoneの 設定 → プライバシーとセキュリティ → Appプライバシーレポート、そしてJustTalkの 設定 → プライバシー → iPhoneから送信されたもの。JustTalkが接続したサービスの一覧で、あなたの言葉は一切含まれません。

料金について

アプリ自体は一度きりの支払いです。モデルはローカルで動かせば無料、クラウドのプロバイダーを使えば従量課金になります——請求するのはそのプロバイダーであって、当方ではありません。Groqで1日10分の音声入力なら、2026年9月時点の料金で月1ドルを大きく下回ります。1日45分としっかり使っても、おおよそ1〜3ドルほどです。7日間はすべての機能がロックなしで使え、クレジットカードも不要です。

お試し期間の後も無料版は使い続けられます。毎日、音声入力2回（1回30文字まで）、フレーズ5回、アクション5回、iPhoneとiPadでは入力修正5回まで。JustTalk Proを一度購入すればすべて無制限になります。クラウドのAIサービスを使う場合、使える量を決めるのはそのサービスの利用条件だけです。サブスクリプションではなく、解約するものもありません。

ローカルかクラウドか——決めるのはあなたで、それぞれの代償はこちらが説明します

JustTalkはモデルを使うためのアプリであり、モデルそのものではありません。ローカルで動かせば — デバイス上で、またはパソコンでOllama、LM Studio、llama.cppなどのモデルサーバーを使って — 何もアップロードされず、料金もかかりません。または、自分で作成したキーでクラウドのプロバイダーに接続：より速く正確で、料金はプロバイダーから直接請求されます。各選択肢が何を送るかはプライバシーポリシーに、どのAIが何をするかはAIについてに書いてあります。 結果がどれだけ正確で、整っていて、速いかは、あなたが選ぶモデルと、それに与えるモードやアクションによって決まります。どちらもいつでも切り替えられます。詳しくは利用規約をご覧ください。

EU AI法の透明性ルールに沿って作られています。あなたが許可するまで、何もAIサービスに送られません。議事録、要約などAIが書いた文章は、アプリ内でもすべての書き出しでもAIが書いたものと表示されます。唯一の例外は音声入力です。整えられて別のアプリに入力されるのはあなた自身の言葉で、そこには表示を付けて渡すことができません。詳しくはAIに関する声明をご覧ください。
